Interaction states

Every control has these five looks. Hover changes only apply where a mouse exists (@media (hover: hover)); a phone shows pressed, never hover. Colour changes take 150 ms and movement 200 ms; with “reduce motion” on, movement is dropped and only the colour change remains. The focus ring is never removed.
